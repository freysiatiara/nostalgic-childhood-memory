A single nostalgic childhood memory in one sentence, written by a small
Python program for the make.fun bounty
[Make the AI Judge Feel Nostalgic: A Childhood Memory](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363).

The line: every rainy afternoon rewinding my father's cassette with a
pencil so the song would play again — not knowing the tape would snap one
day and take his humming with it.

## Run it

```sh
python3 main.py
```

This writes the sentence to `/output/entry.txt` (or to the path in
`ENTRY_OUTPUT` / `OUTPUT_DIR` / `MAKEFUN_OUTPUT_DIR` when set).
